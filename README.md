# Angelina Aung, CAD Portfolio

Mechanical engineering portfolio. Assistive medical devices modeled in SolidWorks, with the sizing reasoning and the things I would do differently written out for each project.

Live at https://angelinaaung-maker.github.io

## Projects

1. **One Handed Pill Dispenser** — a seven day carousel indexed by a flexible pawl against a ratchet, one press per dose
2. **IV Line Organizer Clip** — five keyhole channels on a snap on pole clamp, so a line is identified by position instead of traced by hand
3. **Adjustable Finger Rehab Trainer** — four spring loaded plungers, resistance set independently on each with a threaded plug

## Build

Static site. One HTML file with inline CSS, plus the renders in `images/`. No build step, no dependencies.
